# 💎 FinPulse (핀 & 크립토 펄스)
### Real-Time Stock & Crypto Market Intelligence Platform
*Ultra-modern, stylish, and luxury financial news aggregator with AI market takeaways, live price tickers, Bull/Bear sentiment voting, and Wall Street Native Voice audio briefing.*

---

## 🌟 Key Features

1. **💎 "Diamond Bright & Champagne Emerald" Luxury Aesthetic**:
   - High-contrast frosted glass cards, radiant diamond porcelain light theme, and hedge-fund dark terminal mode.
2. **📈 Live Market Pulse Marquee Ticker**:
   - Real-time animated ticker for BTC, ETH, SOL, XRP, NVDA, TSLA, AAPL, MSFT, S&P 500, and NASDAQ with dynamic 24h price change badges.
3. **🐂 Bullish vs 🐻 Bearish Sentiment Voting**:
   - Real-time community investor sentiment voting and percentage gauge bar on every story.
4. **🤖 AI Financial Analyst & Risk Diagnostic**:
   - 3-bullet executive TL;DR, investor impact analysis (Why It Matters), Market Sentiment rating (`Strong Bullish`, `Bearish`, etc.), and Volatility Risk assessment (`High Volatility`, `Stable`).
5. **🎙️ Wall Street Voice Audio Briefing (US Native Voice)**:
   - High-fidelity natural American financial anchor voice synthesis.
6. **🌐 Dual Language Editions**:
   - 🇰🇷 Korean Edition: `/` (국내외 증권 & 가상자산)
   - 🇺🇸 English Global Edition: `/en` (Global Equities & Crypto Intelligence)
7. **🔔 Morning Market Bell Digest**:
   - Automated daily financial newsletter dispatcher via Formspree and markdown export.

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```

Deployed seamlessly on **[Vercel](https://vercel.com)**.
